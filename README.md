# 213 — Méditerranée

Virtual try-on e-commerce (Next.js 14 + TypeScript + Tailwind).

## Setup

1. Copy env file:

```bash
cp .env.example .env.local
```

2. Fill `OPENROUTER_API_KEY` in `.env.local` (never commit it).

3. Run the dev server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
